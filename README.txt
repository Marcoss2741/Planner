PLANNER - projeto do APK
1. No GitHub, crie um repositorio novo (pode ser privado).
2. Envie TODOS estes arquivos para ele (Add file > Upload files), incluindo a pasta .github e a pasta www.
3. Abra a aba Actions, escolha "Build APK" e toque em Run workflow (ou aguarde: ele roda sozinho ao enviar).
4. Quando terminar (uns 5 a 10 minutos), abra a execucao e baixe "planner-apk" em Artifacts. Dentro do zip esta o app-debug.apk.
5. No celular, abra o APK e permita "instalar apps desconhecidos" quando pedir.
Para mudar o planner no futuro, edite www/index.html e envie de novo: o APK e gerado outra vez.
